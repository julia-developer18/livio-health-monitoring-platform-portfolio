---

## 📌 Архитектурный обзор модулей системы

Платформа спроектирована по модульному принципу и объединяет сервисы мониторинга организма, клиентских записей и хранения медицинской информации:

1. **Модуль аутентификации и профиля (`/login.php`, `/register.php`, `/account.php`, `/profile.php`):**
   * Регистрация и авторизация с валидацией номера телефона (`+7XXXXXXXXXX`) и криптографическим хешированием паролей `Bcrypt` (`password_hash` / `password_verify`).
   * Централизованный агрегатор уведомлений: подсчет активных записей к врачам и заявок на ветеринарную помощь.
   * Управление персональными данными, прикрепление полиса ОМС и медицинской организации.
2. **Кардиологический журнал (`/heart.php`):**
   * Учет инструментальных обследований: ЭКГ, ЭхоКГ, МРТ сердца и КТ-ангиографии.
   * Контекстное добавление, редактирование и удаление записей в модальных интерфейсах.
3. **Модуль антропометрических параметров (`/metrics.php`):**
   * Контроль динамики массы тела, роста, обхватов талии, груди и бедер с проверкой валидности вещественных чисел.
4. **Календарь женского здоровья (`/cycle.php`):**
   * Интерактивный календарный интерфейс на чистом JS с поддержкой асинхронной синхронизации отметок дней через Fetch API (AJAX).
   * Автоматическая группировка отмеченных дней в непрерывные временные интервалы с расчетом продолжительности циклов.
5. **Трекер гидратации (`/water.php`):**
   * Учет суточного потребления жидкости с визуализацией прогресса через интерактивные стаканы объемом 250 мл и настраиваемой дневной нормой.
6. **Дневник питания (`/feed.php`):**
   * Каталог блюд с загрузкой фотографий, контролем MIME-типов (`image/jpeg`, `image/png`, `image/gif`) и каруселью рекомендованного меню.
7. **Телемедицина и сервис заявок (`/doctor.php`, `/veterinary.php`):**
   * Бронирование временных слотов на прием к профильным специалистам.
   * Оформление вызова ветеринара на дом с возможностью прикрепления истории болезни и фото питомца.
8. **Электронная аптека и каталог (`/pharmacy.php`, `/services.php`):**
   * Каталог препаратов и БАДов с клиентской фильтрацией по категориям (Скидки, Лекарства, БАДы) и поисковой строкой в реальном времени.

## 🗄 Реляционная схема базы данных (ER-модель)

База данных `mysite` полностью нормализована. Главная сущность `users` выступает родительской таблицей для всех остальных 7 сущностей, обеспечивая каскадное удаление данных (`ON DELETE CASCADE`):

```text
                           ┌─────────────────────────┐
                           │      users (PK)         │
                           └────────────┬────────────┘
         ┌──────────────┬───────────────┼───────────────┬──────────────┬──────────────┐
         ▼              ▼               ▼               ▼              ▼              ▼
   [cycle_diary]    [dishes]       [metrics]      [heart_exams]   [doctor_app]  [veterinary_req]
                                                                                      │
                                                                                      ▼
                                                                                [water_intake]
```

* **Целостность данных:** Ограничения `UNIQUE KEY` на сочетания `(user_id, date)` защищают от дублирования записей цикла и суточного потребления воды.
* **Индексация:** Композитные индексы по полям `(user_id, date)` и `(user_id, created_at)` ускоряют выборку истории и сортировку записей.

## 🔒 Безопасность и архитектурные решения

* **Защита от SQL Injection:** 100% операций с базой данных реализованы через параметризованные запросы с плейсхолдерами `PDO::prepare()`.
* **Защита от XSS (Cross-Site Scripting):** Все пользовательские входные данные экранируются функцией `htmlspecialchars()` при рендеринге в шаблонах.
* **Изоляция сессий:** Проверка авторизации `$_SESSION['user_id']` на закрытых страницах с автоматическим перенаправлением на страницу входа.
* **Безопасная обработка файлов:** Проверка кода ошибки `UPLOAD_ERR_OK`, валидация MIME-типа, генерация уникальных случайных имен (`uniqid()`) и хранение в изолированной директории `/uploads/`.

## 🛠 Стек технологий

* **Backend:** PHP 8.1+ (Native PHP, PDO MySQL, Session API)
* **Database:** MySQL 8.0 / MariaDB (InnoDB, Prepared Statements, Foreign Keys)
* **Frontend:** TailwindCSS v4, Vanilla JavaScript (ES6+, Fetch API, Touch/Mouse Event Listeners)
* **Архитектурные паттерны:** Модульная монолитная архитектура, Clean Form Handling (PRG pattern).
